   - Deviation from plan: `keytool`'s default keystore type is now PKCS12 (JDK 9+ default),
     which does not support a separate key password from the store password — keytool
     silently ignored the distinct `-keypass` value and used the store password for both.
     `keystore.properties` reflects this: `storePassword` and `keyPassword` are the same
     value. This is standard modern keytool/PKCS12 behavior, not a mistake.
   - Both randomly generated passwords are 32-character base64-derived strings (using
     URL-safe substitutions for `/` and `+` to avoid quoting issues in the `.properties`
     file). The keystore file and its password have been handed to the developer directly
     in this conversation (see chat) and are not stored anywhere in git.
