# TripPlanner

An Android app for planning multi-day trips and keeping all relevant information at hand while
traveling — similar in spirit to Wanderlog or TripIt.

## Development

This app is developed using coding agents. The instructions and design documents are included in this repository. 

## Concepts

- **Trip** — a multi-day thing with a start date, end date, destination, and settings (timezone,
  sync interval).
- **Event** — belongs to a trip; has a start/end date, optional start/end time, and description.
  Examples: a flight, a museum visit, a hotel stay. Flight and Lodging events carry extra
  structured fields (flight number, departure/arrival airport codes, booking number).
- **Note** — belongs to a trip or an event. Types: text block, list (packing/todo), URL, Google
  Docs/Sheets/Drive link, uploaded file, or a `.pkpass` boarding-pass/ticket that renders like in
  Google Wallet.
- **Reminder** — belongs to a trip or an event; a block of text with a date/time for something
  that needs to happen.

## Features

- Home screen listing all trips, with a button to add a new one.
- Opened trip: events grouped into sections per date (undated-first, then sorted by start time;
  multi-day events show "day X of Y" in each section), plus lists of notes and reminders.
- Add events, notes, and reminders from within a trip or an event.
- Per-trip settings (timezone) and global settings (default timezone, sync interval, account).
- Share a trip with another user; export a trip as shareable plain text.
- Sync status bar showing time since last successful sync and a manual sync button.
- Confirmation prompt before deleting anything.
- Edit trip dates, with events outside the new range flagged as invalid.

## Tech stack

- **Language / UI**: Kotlin, Jetpack Compose (Material 3), MVVM + Clean Architecture, Hilt for DI.
- **Local persistence**: Room (offline-first cache), Jetpack DataStore for preferences.
- **Backend**: Firebase — Authentication (Google Sign-In), Cloud Firestore (real-time sync,
  sharing via security rules), Cloud Storage (file/pkpass uploads), Hosting (privacy policy page).
- **Other**: WorkManager (background sync reconciliation), AlarmManager/BroadcastReceiver (local
  reminder notifications), Coil (image loading), ZXing (pkpass barcode rendering), Credential
  Manager API (Google Sign-In).
- Build config: AGP 8.3.2, Kotlin 1.9.22, compileSdk/targetSdk 34, minSdk 24, JVM target 17.

See `DesignDocs/Phase*/techstack.txt` for the full rationale and version-compatibility notes.

## Building

```
cd App
./gradlew assembleDebug
```

Requirements before building:

- `App/app/google-services.json` (Firebase project config — already present in this repo).
- `App/local.properties` with `sdk.dir` (auto-generated by Android Studio) and, optionally,
  `PLACES_API_KEY` / `UNSPLASH_ACCESS_KEY` for trip cover-photo fetching (missing keys just
  disable that feature rather than breaking the build).
- For release builds, `App/keystore.properties` (copy from `App/keystore.properties.example` and
  fill in real values) — see `DesignDocs/Phase2/publishing_manual.txt` for the signing/publishing
  process.

## Development process

This project is built phase by phase; see `instructions.txt` for the full process (phase
description → tech stack → data structure → mockups → implementation plan → block-by-block
implementation → extensions/bug fixes). `progress.txt` tracks current status, and
`DesignDocs/PhaseN/` holds that phase's design documents and verification reports.

- **Phase 1**: Core app — trips, events, notes, reminders, cloud sync/sharing.
- **Phase 2**: Private release to Google Play internal testing.
- **Phase 3**: Global/per-trip settings, sync status bar, delete confirmations, pkpass notes,
  Drive/Docs link notes, structured Flight/Lodging event fields.
- **Phase 4**: Bug fixes and extensions (file notes, date-range validation, per-field timezones,
  etc.) — see `DesignDocs/Phase4/bugs.txt` and `extensions.txt`.
- **Phase 5**: Not started — placeholder for deferred external data integrations (destination
  autocomplete, weather, currency conversion, flight tracking).
